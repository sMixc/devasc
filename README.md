This is the start of the GraphHopper enhancement project.

As of 9/23/2025 the project currently has a web-based GUI but most of the functions from the original activity are kept.

Requirements:
-Python
-Requests
-Streamlit

1. To install Python, download it from their website https://www.python.org/downloads/

2. After installing Python, you may need to install the 'requests' Python package separately.
   -This can be done by running the following command on PowerShell: pip install requests

3. Finally, streamlit is required to actually run the application through your web browser (kind of like xampp)
   -Install streamlit by using the command: pip install streamlit
   -Run the application by using the command: streamlit run \path_to_code\graphhopper_proect.py

Enjou :)
